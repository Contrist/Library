public repo of a private project

we scrape Web Novels from a Website called "RoyalRoad" and then add them to the SQlite Database
we then (run 'python app.py) display all added Web Novels on localhost and can open them by clicking on the cover.
once we are inside the book, we can read the current chapter and navigate chapters, via the buttons on start of the page
